# POV: você é uma variável

Vídeo vertical (1080x1920, 45s) para Reels / TikTok / Shorts, gerado 100% por código, com a trilha sonora incluída.

- `pov_voce_e_uma_variavel.mp4`: o vídeo final
- `gerar_video.py`: o script que gera o vídeo (`python3 gerar_video.py`, precisa de Pillow, NumPy e ffmpeg)

**Legenda sugerida:** "Você só existe enquanto alguém aponta pra você. 🥲 #programacao #javascript #dev #pov"
